INTRODUCTION

Cloud Computing is the delivery of on-demand computing services—including compute servers, storage, databases, networking, and software—over the Internet with pay-as-you-go pricing. Rather than purchasing and managing physical servers, organizations leverage cloud infrastructure provided by Amazon Web Services (AWS) to achieve high availability, fault tolerance, and global scalability.

In this project, CloudLens was architected as a cloud-native image gallery and asset management system. The system leverages AWS EC2 (Elastic Compute Cloud) as the virtualized host environment, AWS S3 (Simple Storage Service) for durable object storage, and a containerized PostgreSQL database for structured metadata persistence.

The front-end is crafted using React.js with a modern responsive glassmorphism UI, while the server-side REST API is built using Node.js and Express.js with integrated AWS SDK and Role-Based Access Control (RBAC).

AIM & SCOPE

To acquire comprehensive practical knowledge of configuring cloud infrastructure on Amazon Web Services (AWS), setting up S3 object storage policies, containerizing applications with Docker & Docker Compose, and deploying a secure full-stack web application onto an AWS EC2 instance.

Frequently Asked Viva-Voce Questions:
  1. What is the difference between AWS S3 and EBS?
    Answer: S3 is an object storage service designed for storing files and media accessed via HTTP, whereas EBS is block storage attached directly to EC2 instances as hard drives.
  2. Why is Docker Compose utilized in this project?
    Answer: It enables multi-container orchestration, allowing PostgreSQL, Node.js Backend, and React Frontend to run in isolated yet interconnected environments.
  3. How is the deletion security handled?
    Answer: Deletion requests require a valid JWT bearer token verified by the backend auth middleware.
  4. What is the purpose of the Fallback Mechanism?
    Answer: If AWS S3 credentials or PostgreSQL are unavailable locally, the system automatically redirects to local disk storage and JSON database without crashing.
